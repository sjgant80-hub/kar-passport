# Kar's passport

**Live: https://sjgant80-hub.github.io/kar-passport/**

Kar's memory holds the estate's context. The passport carries a slice of it to a fresh AI session (a new Kar, Grok,
a collaborator's AI, any model) as a pasteable [SYMB-FER](https://github.com/SYMBEYOND/SYMB-FER) v6.2 token, sealed,
checked before it is read, and taken back into memory when the session hands it back.

SYMB-FER is SYMBEYOND AI LLC's open protocol (MIT): *SYMB-FER, SYMBEYOND AI LLC, 2026.*

`claims.json` is sealed before any code. Everything below it is measured against it.
